API do Holdprint

Duas formas de integrar por HTTP: a API /v1, nova, que serve à CLI, ao MCP, aos plugins e a apps externos, e a API Key, mais antiga, para integração entre sistemas com uma chave fixa.

Qual usar#

API /v1 (recomendada)API Key (legada)
Como entraLogin de um usuário pelo navegador (CLI, MCP, plugin ou app externo). A chamada vê só o que esse usuário vê no Holdprint.Chave fixa gerada em Ajustes > API/MCP, no cabeçalho x-api-key.
O que cobreConsulta com filtros de 7 recursos, leitura por id de 27 cadastros, tarefas, etapa do funil, eventos e as 1.474 ações do sistema pela CLI e pelo MCP.Clientes, fornecedores, orçamentos, jobs, contas a pagar e a receber e cadastros financeiros.
Endereço{BASE_URL}/v1https://api.holdworks.ai
Para quemA IA da gráfica, plugins e automações que agem em nome de um usuário.Integração servidor a servidor com outro ERP, BI ou loja.

Comece pela CLI#

A CLI holdprint faz o login, guarda a sessão e chama a API /v1 por você. É o caminho mais curto para a sua IA consultar e operar a conta.

Nesta seção#

  • API /v1: endereço, autenticação, rotas, paginação, eventos, cotas e formato de erro.
  • Consultas por recurso: campos, filtros e ordenações de cada recurso, com o comando da CLI.
  • Ações pela CLI e MCP: como a IA descobre, confere e executa as 1.474 ações do sistema.
  • API Key (legada): as rotas com chave fixa, mantidas para integrações existentes.
